# ⏳ Contador Regressivo para Lançamento de Projetos

## 📌 Sobre o projeto

Projeto de uma página web com contador regressivo personalizável, desenvolvido para exibir a contagem de tempo até o lançamento de projetos, eventos, campanhas ou outras datas importantes.

A aplicação permite configurar um título personalizado e acompanhar a contagem regressiva em **dias, horas, minutos e segundos**.

Desenvolvido com foco na utilização em painéis, dashboards e telas de apresentação, oferecendo uma interface simples, objetiva e de fácil configuração.

## 🚀 Funcionalidades

- **Contador regressivo:** exibição dinâmica de dias, horas, minutos e segundos.
- **Título personalizado:** permite definir o nome ou objetivo da contagem.
- **Configuração de data:** definição da data e horário do lançamento.
- **Modo de exibição limpo:** permite ocultar os campos de configuração por meio de um botão na própria tela.
- **Parâmetro de URL:** permite iniciar a página diretamente sem os campos de configuração utilizando `?limpo=1`.
- **Atualização automática:** contador atualizado em tempo real.

## 🛠️ Tecnologias utilizadas

O projeto utiliza tecnologias simples e nativas do desenvolvimento web:

- HTML5 — estrutura da página.
- CSS3 — estilização e responsividade.
- JavaScript — lógica do contador e interatividade.

## 💻 Como utilizar

1. Abra a página web no navegador.
2. Informe o título desejado.
3. Configure a data e o horário do lançamento.
4. Inicie a contagem regressiva.
5. Utilize o botão de ocultar configurações para deixar a tela mais limpa.

### Modo de exibição limpo

Para abrir a página sem exibir os campos de configuração, basta adicionar o parâmetro abaixo ao endereço:

```text
?limpo=1
```

Exemplo:

```text
https://seusite.com/contador/?limpo=1
```

Esse recurso é especialmente útil para exibição em monitores, televisores, painéis internos e dashboards.
